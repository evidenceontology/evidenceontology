# About:
# This mapping translates GO root evidence codes used in a GAF to a specific evidence type in ECO
# Previously, this file included mappings between GO root evidence codes, GO_REFs and ECO term identifiers. As of January 2026, all GO_REFs and their associated mappings have been removed. These mappings are now maintained by the Gene Ontology team and are available at: https://github.com/geneontology/go-site/blob/master/metadata/eco-usage-constraints.yaml. 
# This file now contains the default ECO identifiers corresponding to GO root evidence codes.
#
# Each mapping in this file constitues:
#  1. GO root evidence code (e.g. IEA)
#  2. The value 'Default' in column 2 is used for the mapping if no more specific mapping can be found
#  3. ECO ID
#
# This document consists of these comments (after #s) followed by a set of mappings, each represented as the above 3 columns separated by tabs
#
# For example an 'IEA' GO root evidence code by default maps to ECO:0000501 ('evidence used in automatic assertion')
#
# To request changes in the mappings, submit an item to
#  https://github.com/evidenceontology/evidenceontology/issues
#
